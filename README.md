# Nexus

多智能体协作平台 —— 连接知识、代码与可视化的 AI 工作流引擎。

## 定位

Nexus 是一个通用的多智能体协作平台，支持：

- 🤖 **多 Agent 编排** — 主 Agent 拆解任务，子 Agent 并行执行
- 🔌 **MCP 协议集成** — 标准化连接外部数据源和工具
- 📚 **知识管理** — 文档导入、语义检索、知识图谱
- 👁️ **可视化面板** — 实时查看 Agent 协作过程
- ☁️ **云端部署** — 7×24 小时持续运行

## 应用场景

| 场景 | 说明 |
|---|---|
| 科研助手 | 论文检索、摘要、对比、知识关联 |
| 代码协作 | 多 Agent 分工完成编码、审查、测试 |
| 数据分析 | 数据清洗、分析、报告生成 |
| 知识库 | 自动归类、语义搜索、定期更新 |

## 技术栈

- **语言**: Python 3.11+
- **协议**: MCP (Model Context Protocol)
- **存储**: SQLite + LanceDB (向量检索)
- **部署**: Docker + 云服务器
- **可视化**: Web UI

## 快速开始

```bash
# 安装依赖
pip install -e .

# 启动
python -m nexus
```
